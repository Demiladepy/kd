# Frequently Asked Questions

**Q: Why USDC instead of sending Naira directly?**
A: Our Chinese suppliers prefer dollar stablecoin (USDC). It settles faster and avoids international bank transfer issues.

**Q: What if I pay late after the quote expires?**
A: Quotes are only valid for 10 minutes. If it expires, we'll need to create a new quote with the current rate.

**Q: Can I pay part now and part later?**
A: No, each payment must cover the full invoice amount for that quote. Split payments aren't supported - please create separate quotes if needed.

**Q: Can I add a new supplier?**
A: No, only pre-saved suppliers can be paid through KudiDesk. To add a new supplier, you'll need to speak to a human operator.

**Q: Can I send money to a different wallet address?**
A: No, for security reasons money can only go to pre-saved supplier wallets. I cannot accept or change wallet addresses.

**Q: What if my payment fails?**
A: If your Naira payment fails on Paystack, no money moves. You can try again with the same link or get a new one.

**Q: How do I know the supplier received the money?**
A: After settlement, I'll share an Arcscan explorer link where you can verify the USDC transfer on-chain.

**Q: Is this real money?**
A: This is a test/demo environment using Paystack test mode and Arc testnet. No real money is involved.
